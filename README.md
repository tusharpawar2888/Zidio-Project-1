# 📈 Time Series Analysis and Forecasting for Stock Market

## 📌 Project Overview

This project focuses on **Stock Market Data Analysis and Time Series Forecasting** using historical stock market data. The objective is to analyze stock price trends, visualize market behavior, and predict future stock prices using various forecasting techniques.

The project is developed using **Python** and **Streamlit**, providing an interactive dashboard for data exploration, visualization, and forecasting.

---

## 🚀 Features

### 📊 Data Analysis

* Dataset overview and summary statistics
* Data cleaning and preprocessing
* Missing value handling
* Duplicate record removal
* Date format conversion

### 📈 Data Visualization

* Stock Closing Price Trends
* Monthly Average Price Analysis
* Candlestick Charts
* Trading Volume Analysis
* Correlation Heatmaps
* Boxplots for Price Distribution
* Daily Return Distribution

### 🔍 Time Series Analysis

* Stationarity Testing using ADF Test
* Differencing for Non-Stationary Data
* ACF (Auto Correlation Function) Plot
* PACF (Partial Auto Correlation Function) Plot

### 🤖 Forecasting Models

* ARIMA Model
* SARIMA Model
* Prophet Model (Optional)
* LSTM Neural Network Model (Optional)

### 🌐 Interactive Dashboard

* Built with Streamlit
* User-friendly interface
* CSV file upload functionality
* Dynamic forecasting period selection
